# Personal Development Preferences

User-level memory (Strategy 1, middle layer of the pyramid).
This file is NOT read from the repository. Copy it to `~/.claude/CLAUDE.md` so it applies
to every project on your machine; it is kept here only so the instructors can see it.

## Code Style
- Python 3, plain functions first, a class only when it holds state.
- Descriptive variable names; constants in CAPS.
- Short comments that explain why, not what.

## Workflow Shortcuts
- Run a notebook top to bottom before calling it done:
  `jupyter nbconvert --to notebook --execute --inplace <file>.ipynb`
- Seed every random run.
- Explain results in plain language before showing tables.
